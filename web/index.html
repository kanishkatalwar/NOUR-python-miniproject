      Min-heap

      Array form first, then the same heap drawn as a tree. The root is always the unit closest to expiry.

      Actions

      Issue takes the root with extractMin. Receive inserts a new unit.

      Units in issue order

      A sorted copy for reading. The heap itself only guarantees the root.

      Emergency requests

      Max-heap. Highest priority leaves first, ties go to the earlier request.

        Routine requests

        Circular queue with 6 slots. F is the front, R is the rear.

        Raise a request

        Priority 4 and above goes to the emergency heap, the rest to the routine queue.

        Process next

        Takes the top emergency request, or the front routine request when there is none. Uses the exact group first, then the best fallback from the compatibility graph.
